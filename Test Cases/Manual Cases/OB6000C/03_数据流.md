# OB6000C 数据流用例（DATA-*）

> 按设备实际能力执行：`getDeviceInfo()` 对应 `ChannelCount>0` 的模态才执行；否则记录"不支持，跳过"。
> OB6000C 为 EEG 脑电设备，核心数据流为 `NTF_EEG`。IMU（ACC/Gyro/Euler/Quat）、ECG、PPG/SpO2、BRTH、Impedance、MagAngle 等通道能力需通过 `getDeviceInfo()` 运行时确认，不做硬编码假设。

- **流程与逻辑**：Ready 后 `init(5, 1000)`，读返回与 `hasInited`。

- **有效性说明**：init 是起流前置。
- **可自动化**：auto
