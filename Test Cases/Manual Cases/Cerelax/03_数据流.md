# Cerelax 数据流用例（DATA-*）

> 按设备实际能力执行：`getDeviceInfo()` 对应 `ChannelCount>0` 的模态才执行；否则记录"不支持，跳过"。
> Cerelax 为 **2 通道脑电头环**，核心数据流为 `NTF_EEG`。PPG、IMU（聚合流或四路独立，待确认）、Impedance（电极接触检测）为 Cerelax 重点通道；ECG/EMG/GEST/BRTH 预计不支持。所有能力需通过 `getDeviceInfo()` 运行时确认，不做硬编码假设。

### DATA-BND-001 init(packageSampleCount) 6 点边界
- **测试目的**：验证批大小边界。
- **边界定义（依据）**：`MAX = 2147483647`（int32 上限）。README 未文档化 `packageSampleCount` 上限；该参数为 C 扩展 int32 入参，故以 int32 max 为假设上限，实测若 SDK 有文档化上限则按文档调整。合法范围 `≥1`。
- **流程与逻辑**：分别传 `1、2、MAX-1、MAX、0、MAX+1`。
- **预期结果**：合法值（`1/2/MAX-1/MAX`）不崩溃不抛异常（MAX-1/MAX 若返回 False 可能超出 SDK 实际上限，标注"需确认"）；非法值（`0/MAX+1`）被拒绝或抛异常且不崩溃；任一边界值导致进程崩溃判 FAIL。
- **有效性说明**：边界健壮性。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
