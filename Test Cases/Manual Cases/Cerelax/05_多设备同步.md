# Cerelax 多设备同步用例（MULTI-*）

> 本组需 **≥2 台设备**。Cerelax 可与同型号或其他型号（如 OB6000C/OYWW1100）混合组合同步。若只有 1 台，整体"跳过（缺设备）"，不判失败。
> 签名（0.9.1）：`multiStartDataNotification(sensors, timeout=30.0, maxDelayDispersionMs=5, maxAttempts=3)`；`multiStopDataNotification(sensors, timeout=10.0)`。

### MULTI-FUNC-001 两台同时起流
- **优先级**：P0
- **测试目的**：验证多设备同步起流。
- **流程与逻辑**：连接 init 两台，`multiStartDataNotification([s1,s2])`，检查返回 `{mac: bool}` 与两台上流。
- **预期结果**：两台均起流。
- **有效性说明**：同步起流核心能力。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### MULTI-BND-001 multiStart/multiStop 空集合/None/单台/非法参数
- **优先级**：P1
- **测试目的**：验证多设备接口的空/None/非法入参。
- **流程与逻辑**：`multiStartDataNotification([])`、`multiStartDataNotification(None)`、`multiStartDataNotification([s1])`（单台）、`timeout=0`/`timeout=-1`、`maxDelayDispersionMs` 取非负整数域外值、`maxAttempts=0`/`maxAttempts=-1`；`multiStopDataNotification([])`/`multiStopDataNotification(None)` 同理。
- **预期结果**：空/None 被拒绝（返回空 dict / False / 抛异常均可）且不崩溃；单台不崩溃；非法参数被拒绝或按文档语义处理。
- **有效性说明**：集合接口健壮性，防止空集合导致崩溃或误起流。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
