# Cerelax 异步接口用例（ASYNC-*）

> 覆盖 async 变体接口，补齐同步用例的覆盖缺口。
> 说明：所有 async 方法需在 asyncio 事件循环中 `await` 调用（可用 `asyncio.run(...)` 包裹）。
> 签名与同步版本一致，仅返回可等待对象；`asyncMulti*` 需 ≥2 台，缺设备则"跳过"。

### ASYNC-FUNC-001 asyncScan 返回设备列表
- **测试目的**：验证异步扫描。
- **流程与逻辑**：`await SensorControllerInstance.asyncScan(5000)`，遍历结果检查是否含 Cerelax。
- **预期结果**：返回 `list[BLEDevice]`，含 Cerelax，与同步 `scan` 结果一致。
- **有效性说明**：异步扫描链路正确。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
