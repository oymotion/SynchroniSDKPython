# Cerelax 控制器与扫描用例（CTRL-*）

### CTRL-FUNC-001 蓝牙未开启时 isEnable==False，startScan 被拒绝
- **优先级**：P0
- **测试目的**：验证控制器感知蓝牙状态并在关闭时拒绝扫描。
- **流程与逻辑**：关闭蓝牙 → 读 `isEnable` → 调 `startScan(3000)`/`scan(3000)`，观察返回值与 `isScanning`。
- **预期结果**：`isEnable==False`；不进入扫描态，`isScanning==False`。
- **有效性说明**：若蓝牙关闭仍能"成功扫描"，说明 SDK 未校验硬件使能，属缺陷。
- **可自动化**：semi-auto
- **人工介入**：人工关闭/开启蓝牙开关。
- **测试结果**：待测试

### CTRL-BND-001 startScan(period_in_ms) 6 点边界
- **优先级**：P1
- **测试目的**：验证扫描周期参数边界。
- **边界定义（依据）**：`MAX = 2147483647`（int32 上限）。README 仅声明 `startScan(period_in_ms: int)` 未文档化周期上限；`period_in_ms` 为 C 扩展 int32 入参，故以 int32 max 为假设上限，实测若 SDK 有文档化上限则按文档调整。
- **流程与逻辑**：分别传 `0、1、MAX-1、MAX、-1、MAX+1`，观察返回与是否抛异常。
- **预期结果**：合法值（`0/1/MAX-1/MAX`）不抛异常（返回 True/False 均记录，False 可能因蓝牙未开启）；非法值（`-1/MAX+1`）被拒绝或抛异常且不崩溃；任一边界值导致进程崩溃判 FAIL。
- **有效性说明**：参数边界健壮性。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
