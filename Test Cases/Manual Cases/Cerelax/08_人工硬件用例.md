# Cerelax 人工硬件用例（HW-MAN-*）

> 本文件为需要人工/仪器介入的硬件相关用例。
> HW-MAN-004（24h 老化）、HW-MAN-005（高低温）超出 SDK 软件测试范围，归硬件/可靠性团队，不在此展开。

### HW-MAN-001 BLE 链路 RSSI/连接稳定性人工验证
- **测试目的**：验证真实环境 BLE 链路稳定性。
- **流程与逻辑**：在不同距离/遮挡下观察 RSSI 变化与断连情况。
- **预期结果**：有效范围内稳定，超出范围按预期断连并可恢复。
- **有效性说明**：真实射频环境验证。
- **可自动化**：manual
- **人工介入**：移动设备、改变距离/遮挡，记录现象。
- **测试结果**：待测试

### HW-MAN-002 dongle 驱动绑定（仅 dongle 后端）
- **测试目的**：验证 dongle 引导。
- **流程与逻辑**：插拔 dongle，`checkSetupDongle()` 引导绑定。
- **预期结果**：绑定成功后可扫描。
- **有效性说明**：dongle 链路。
- **可自动化**：manual
- **人工介入**：插拔 dongle、装驱动。
- **测试结果**：待测试

### HW-MAN-003 供电电压/上掉电时序与 SDK 重连
- **测试目的**：验证断电恢复。
- **流程与逻辑**：断电再上电，观察 SDK 自动重连。
- **预期结果**：恢复连接（SDK 侧）。
- **有效性说明**：SDK 断电恢复响应。
- **可自动化**：manual
- **人工介入**：断电/上电。
- **测试结果**：待测试

### HW-MAN-006 头环佩戴与电极接触检测人工验证
- **测试目的**：验证头环佩戴与 `NTF_IMPEDANCE` 电极接触检测。
- **流程与逻辑**：佩戴头环 → 起 `NTF_IMPEDANCE` → 观察阻抗读数；故意松脱一个电极 → 观察阻抗变化与数据有效性。
- **预期结果**：正常佩戴时阻抗读数合理；松脱电极时阻抗异常/数据标记无效，恢复接触后恢复。
- **有效性说明**：Cerelax 头环的电极接触检测是数据质量前置，需人工佩戴验证。
- **可自动化**：manual
- **人工介入**：佩戴头环、松脱/恢复电极接触。
- **测试结果**：待测试
