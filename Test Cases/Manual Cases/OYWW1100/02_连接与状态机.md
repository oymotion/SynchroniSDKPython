# OYWW1000 连接与状态机用例（DEV-SM-*）

> 下列用例均针对 OYWW1000 单台执行。

### DEV-SM-001 connect 成功，状态迁移 Disconnected→Connecting→Connected→Ready
- **测试目的**：验证连接成功与状态迁移序列。
- **流程与逻辑**：注册 `onStateChanged`，`requireSensor` 后 `connect()`，记录每次状态变化。
- **预期结果**：返回 True，按 `Disconnected→Connecting→Connected→Ready` 迁移，最终 `deviceState==Ready`、`isReady==True`。
- **有效性说明**：连接是后续操作前提；迁移顺序错误会导致指令在错误状态下发送。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### DEV-SM-002 connect 失败返回 False 并回调原因
- **测试目的**：验证连接失败路径。
- **流程与逻辑**：对已关机/超出范围的设备 `connect()`，观察返回与 `onErrorCallback`。
- **预期结果**：返回 False，`onErrorCallback` 收到原因。
- **有效性说明**：失败可观测、不静默。
- **可自动化**：semi-auto
- **人工介入**：人工关闭设备电源或移出范围。
- **测试结果**：失败，问题 7067

### DEV-SM-003 非目标前缀设备不误连接
- **测试目的**：验证不误连其它设备。
- **流程与逻辑**：扫描到非 OYWW 前缀设备，`requireSensor` 后确认不会自动连接目标 OYWW1000。
- **预期结果**：只连接显式指定的设备。
- **有效性说明**：防止串设备。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### DEV-SM-004 disconnect 成功，Ready→Disconnecting→Disconnected
- **测试目的**：验证主动断开与状态迁移。
- **流程与逻辑**：Ready 后 `disconnect()`，记录状态迁移与返回。
- **预期结果**：返回 True，最终 `deviceState==Disconnected`，`onStateChanged` 触发。
- **有效性说明**：断开干净、状态正确。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### DEV-SM-005 起流中 disconnect 自动先停流
- **测试目的**：验证断开前自动停流。
- **流程与逻辑**：起流后直接 `disconnect()`，观察是否先停流再断开。
- **预期结果**：无异常，`isDataTransfering` 最终 False，连接断开。
- **有效性说明**：避免传输中硬断开导致资源问题。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过
