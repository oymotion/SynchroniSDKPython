# OYWW1000 参数用例（PARAM-*）

### PARAM-FUNC-001 每个 NTF_* 键 ON/OFF 返回 OK，getParam 一致
- **测试目的**：验证数据流开关。
- **流程与逻辑**：对适用键（`NTF_EMG`/`NTF_GEST`/`NTF_IMU`/`NTF_GFORCE_ACC`/`NTF_GFORCE_GYRO`/`NTF_GFORCE_EULER`/`NTF_GFORCE_QUAT`）逐一 `setParam("ON"/"OFF")`，`getParam("NTF")` 核对；`NTF_MAG_ANGLE`/`NTF_SPO2`/`NTF_PPG`/`NTF_PPG_RAW` 按 `getDeviceInfo()` 对应 `ChannelCount` 判定（>0 测，==0 记录“不适用，跳过”）。
- **预期结果**：返回 `OK`，`getParam` 状态一致。
- **有效性说明**：参数读写一致。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### PARAM-FUNC-002 FILTER_* 键 ON/OFF
- **测试目的**：验证滤波开关（EMG 50/60Hz 工频陷波、高通/低通）。

- **预期结果**：返回 `OK`，状态一致。
- **有效性说明**：滤波参数生效。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### PARAM-FUNC-004 EMG_SAMPLE_RATE 设置 500/1000 + 非法值 750
- **测试目的**：验证 EMG 采样率设置（500/1000 两档，默认 1000）。
- **流程与逻辑**：`connect` 到达 `Ready` 并 `init` 后、未做任何 `setParam("EMG_SAMPLE_RATE")` 之前，首次 `getParam("EMG_SAMPLE_RATE")` 即为上电默认值 `1000`；`getParam("EMG_SAMPLE_RATE_LIST")` 应返回含 `500`/`1000` 的可选值；逐一 `setParam("EMG_SAMPLE_RATE","500"/"1000")` 后 `getParam("EMG_SAMPLE_RATE")` 读回一致；`setParam("EMG_SAMPLE_RATE","750")` 与空串返回 `Error`。
- **预期结果**：500/1000 设置成功并读回一致，上电默认 1000；非法值 750 与空串被拒绝（返回 `Error` 或抛异常）。
- **有效性说明**：EMG 采样率参数读写一致 + 非法输入容错。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
