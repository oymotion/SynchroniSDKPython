# OYWW1000 数据流用例（DATA-*）

> 按设备实际能力执行：`getDeviceInfo()` 对应 `ChannelCount>0` 的模态才执行；否则记录“不支持，跳过”。

- **流程与逻辑**：Ready 后 `init(5, 1000)`，读返回与 `hasInited`。
- **预期结果**：返回 True，`hasInited==True`。
- **有效性说明**：init 是起流前置。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：通过

### DATA-FUNC-005 各 DataType 流能收到对应 SensorData
- **测试目的**：验证 OYWW1000 支持的数据流类型。
- **流程与逻辑**：对每个适用 DataType（`NTF_EMG`/`NTF_GEST`/`NTF_ACC`/`NTF_GYRO`/`NTF_EULER_DATA`/`NTF_QUATERNION` 及待确认项）分别 `setParam(...,"ON")` 后起流，统计 `getDataType()`。
- **预期结果**：`ChannelCount>0` 的流均能收到数据且 `getDataType()` 匹配；`ChannelCount==0` 记录“不支持”。
- **有效性说明**：逐模态验证真实能力，避免遗漏/误判。
- **可自动化**：auto（能力判定自动；运动激发见下）
- **人工介入**：若需触发手势/运动产生数据，人工做手势/晃动；否则纯 auto。
- **测试结果**：失败，问题 7069
