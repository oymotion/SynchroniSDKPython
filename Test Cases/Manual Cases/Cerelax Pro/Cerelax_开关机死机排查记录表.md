# Cerelax 开关机死机排查记录表

> 背景：Cerelax 头环出现「看门狗复位循环」死机现象（扫描能发现、一连上 2~3 秒即被重启断开）。
> 新线索：死机在**设备开机时**出现。本表用于通过一组开关机动作，定位哪种开机方式最容易复现死机。
> 性质：临时排查记录表（非正式用例），现场手动执行并打勾/填写。

---

## 一、按键与 LED 定义（已确认）

### 按键定义

| 按键 | 时长 | 作用 |
|------|------|------|
| 短按 | ≈1s | 无作用 |
| 长按 | ≈2s | 开机 / 关机（toggle） |
| 超长按 | ≈10s | 进入 boot 模式 |

### LED 含义

| LED 表现 | 颜色 | 含义 |
|----------|------|------|
| 慢闪 | 绿 | 待连接（已开机、未连接） |
| 常亮 | 绿 | 已连接、未传数据 |
| 快闪 | 绿 | 连接中、传数据中 |
| 常亮/闪烁 | 橘黄 | 充电中 |
| 灭 | — | 满电 |
| 其他 | 绿 | 正常非充电状态 |

---

## 二、判定"死机"的观察手段

- **LED**：开机后 LED 应进入「慢闪（待连接）」；若熄灭 / 异常闪烁 / 颜色异常，可能异常。
- **连接后 LED 状态机**：慢闪 → 常亮（已连接）→ 快闪（传数据）；若连接即断，LED 会掉回慢闪或异常。
- **能否连接**：连上后是否 **2~3 秒又断开**（复位循环特征，用 SDK / APP 判）。
- **SDK 辅助**：开机后用 `crash_triage.py` 或直接 connect 观察是否「连上即断」。

---

## 三、执行原则（单变量法）

1. 每次只变一个变量（按键时长 / 充电状态 / 电量），别混着改。
2. 每个动作间留 3~5 秒让设备稳定。
3. 每次开机后都做「连接判死」：开机 → 立即尝试 connect，看是否「连上即断」。

## 四、动作矩阵（执行指引）

### A 组：基础开关机（长按 2s）

| # | 动作 | 操作 | 观察点 |
|---|------|------|--------|
| A1 | 长按 2s 开机 | 长按约 2s 松手 | LED 是否进入慢闪（待连接） |
| A2 | 长按 2s 关机 | 开机稳定后长按 2s | LED 是否熄灭 |
| A3 | 短按测试 | 开机后短按 1s | 确认无作用，LED 不变 |
| A4 | 开机后立即连接 | 长按 2s 开机 → 立即 SDK connect | 是否正常连接（常亮→快闪） |

### B 组：长按时长边界（找开关机阈值）

| # | 动作 | 操作 | 观察点 |
|---|------|------|--------|
| B1 | 长按 1.5s | 按住 1.5s 松手 | 不到 2s，是否不开机 |
| B2 | 长按刚好 2s | 精确 2s 松手 | 是否正常开机 |
| B3 | 长按 3s | 按住 3s 松手 | 超过 2s，是否正常开机/关机 |
| B4 | 长按 5s | 按住 5s 松手 | 介于 2s~10s，是否异常 |
| B5 | 长按 8s | 按住 8s 松手 | 接近 10s，是否误进 boot |

### C 组：boot 模式（长按 10s，重点怀疑）

| # | 动作 | 操作 | 观察点 |
|---|------|------|--------|
| C1 | 长按 10s 进 boot | 长按直到进 boot | LED 表现？boot 模式是否死机 |
| C2 | boot 后恢复 | 进 boot 后长按 2s 退出 | 能否正常退出 boot |
| C3 | boot 后直接连接 | 进 boot 后尝试连接 | 能否连接 / 是否复位循环 |
| C4 | 长按 9s 松手 | 长按 8~9s 松手（未到 10s） | 是否卡在中间态 |

### D 组：充电/电量相关（长按 2s 开机）

| # | 动作 | 操作 | 观察点 |
|---|------|------|--------|
| D1 | 充电中长按开机 | 插充电器，长按 2s 开机 | LED 橘黄？开机是否正常 |
| D2 | 低电量长按开机 | 低电量时长按 2s 开机 | 低电量开机是否死机 |
| D3 | 开机后立即插充电器 | 开机稳定后插充电器 | LED 变橘黄，是否复位 |
| D4 | 满电长按开机 | 满电（灯灭）时长按 2s 开机 | 满电开机是否正常 |
| D5 | 充电中长按 10s | 充电中长按 10s 进 boot | 充电态进 boot 是否异常 |

### E 组：时序/快速切换（找「开机瞬间」死机）

| # | 动作 | 操作 | 观察点 |
|---|------|------|--------|
| E1 | 关机后立即开机 | 长按关机 → <1s 再长按开机 | 快速关开是否复位循环 |
| E2 | 开机后立即关机再开机 | 开→关→开，间隔 <1s | 连续时序切换 |
| E3 | 连续开关机循环 | 长按开关循环 10 次，间隔 2s | 累计是否偶发死机 |
| E4 | 死机后长按恢复 | 复位循环时长按 2s / 10s | 能否救回 / 复位 |
| E5 | 关机态长按 15s | 关机状态长按 15s 不松 | 超长按是否异常（boot 后持续） |
