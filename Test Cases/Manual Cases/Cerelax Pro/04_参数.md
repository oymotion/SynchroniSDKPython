# Cerelax 参数用例（PARAM-*）

> Cerelax 为 **2 通道脑电头环**，核心参数为 `EEG_SAMPLE_RATE`（唯一合法值 `250`）。
> **重要**：SDK 1.3.0 已文档化 EEG/IMU/PPG 三套采样率的 `setParam`/`getParam`（含 `_LIST` 可选值查询）：`EEG_SAMPLE_RATE`（Cerelax 唯一合法值 `250`）、`IMU_SAMPLE_RATE`（仅扩展 IMU 能力设备；旧固件固定 50Hz 且 `IMU_SAMPLE_RATE_LIST` 为空）、`PPG_SAMPLE_RATE`（PPG 设备）。按 `getDeviceInfo()` 对应 `ChannelCount>0` 运行时判定能力，不支持则返回 `Error`，不做硬编码假设。
> `NTF_*` 流开关、`FILTER_*` 滤波开关等按 `getDeviceInfo()` 运行时判定能力，不做硬编码假设。

### PARAM-FUNC-001 每个 NTF_* 键 ON/OFF 返回 OK，getParam 一致
- **优先级**：P0
- **测试目的**：验证数据流开关。
- **流程与逻辑**：对适用键（`NTF_EEG` 为核心；`NTF_PPG`/`NTF_IMU`（或四路 `NTF_GFORCE_*`）/`NTF_IMPEDANCE` 为重点；`NTF_SPO2`/`NTF_ACC`/`NTF_GYRO`/`NTF_EULER_DATA`/`NTF_QUATERNION`/`NTF_MAG_ANGLE_DATA` 按 `getDeviceInfo()` 对应 `ChannelCount` 判定，>0 测，==0 记录"不适用，跳过"；头环无 ECG/EMG/BRTH，不测）逐一 `setParam("ON"/"OFF")`，`getParam("NTF")` 核对。
- **预期结果**：返回 `OK`，`getParam` 状态一致。
- **有效性说明**：参数读写一致。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### PARAM-FUNC-004 EEG_SAMPLE_RATE 设置（含逆向：500 非法）
- **优先级**：P0
- **测试目的**：验证 EEG 采样率设置（Cerelax 核心功能），含非法值逆向。
- **流程与逻辑**：从 `getParam("EEG_SAMPLE_RATE_LIST")` 获取可选值列表（预期仅 `250`），`setParam("EEG_SAMPLE_RATE", "250")` 后 `getParam("EEG_SAMPLE_RATE")` 核对；另测逆向值 `setParam("EEG_SAMPLE_RATE", "500")` 期待返回 `Error`（`500` 为非法值）。Cerelax 无 ECG，仅 EEG 单模态。
- **预期结果**：合法值 `250` 设置返回 `OK`、`getParam` 一致；非法值 `500` 返回 `Error` 且不改变当前采样率。
- **有效性说明**：EEG 采样率是 Cerelax 核心参数（仅支持 `250`）；`500` 非法值逆向验证防止"越界值被误接受"。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试

### PARAM-FUNC-011 getParam IMU/PPG_SAMPLE_RATE 与 _LIST（能力门控）
- **优先级**：P1
- **测试目的**：验证 IMU/PPG 采样率的查询接口（SDK 1.3.0 已文档化 `getParam("IMU_SAMPLE_RATE"/"IMU_SAMPLE_RATE_LIST")`、`getParam("PPG_SAMPLE_RATE"/"PPG_SAMPLE_RATE_LIST")`）。
- **流程与逻辑**：Ready + init 后，若 `getDeviceInfo()` 对应 `ImuChannelCount>0` / `PpgChannelCount>0`，分别 `getParam` 当前值与 `_LIST`；能力缺失时也应读一次（期待返回 `Error` 或空列表）。起流后用实测数据率与查询值比对（IMU 标称 `50|100|200` 之一，PPG 标称 `50|100|200|400` 之一）。
- **预期结果**：支持时返回当前采样率与管道分隔可选值列表（`>0`），实测数据率与之相符（允许容差 ±5%）；不支持时返回以 `Error` 开头或空列表，不崩溃。
- **有效性说明**：查询接口正确，覆盖能力门控下的正/反两向。
- **可自动化**：auto
- **人工介入**：无
- **测试结果**：待测试
